<h1 align="center">Yandex Search AdBlocker</h1>

<p align="center">
  Чистая поисковая выдача Яндекса без навязчивых рекламных и промо-блоков.
</p>

## Установка

Рекомендуемый вариант: загрузить в браузере корневую папку проекта:

```text
C:\Users\user\Desktop\Yandex-Search-AdBlocker-main
```

Также можно загрузить эту папку `yandex-ad-blocker`, потому что внутри нее сохранен отдельный `manifest.json`.

## Что внутри

| Файл | Назначение |
| --- | --- |
| `content.js` | Основная логика поиска и скрытия рекламы |
| `styles.css` | CSS для уже помеченных рекламных элементов |
| `popup.html` | Интерфейс попапа расширения |
| `popup.js` | Статус, статистика и отключение для текущей страницы |
| `manifest.json` | Manifest V3 для загрузки этой подпапки |
| `icon*.png` | Иконки расширения |

Полное красивое описание проекта лежит в [корневом README](../README.md).
