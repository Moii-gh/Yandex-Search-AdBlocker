# Yandex Search AdBlocker

Эту папку можно загрузить как отдельное распакованное расширение. Основной вариант установки - выбрать корневую папку проекта:

```text
C:\Users\user\Desktop\Yandex-Search-AdBlocker-main
```

## Что внутри

| Файл | Назначение |
| --- | --- |
| `content.js` | Поиск рекламных признаков в DOM и скрытие найденных блоков |
| `styles.css` | CSS для элементов, уже помеченных `content.js` |
| `style.css` | Внешний вид попапа расширения |
| `popup.html` | Интерфейс попапа |
| `popup.js` | Статус, статистика и отключение блокировки для текущей страницы |
| `manifest.json` | Manifest V3 для загрузки этой подпапки |
| `icon*.png` | Иконки расширения |

Подробная инструкция лежит в [корневом README](../README.md).
